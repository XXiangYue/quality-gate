# Quality Gate 中文导读

在 AgentRewardBench 的 WebArena 子集上复现 WebJudge，比较原始初判、选择性复核和复核所有拒绝。共完成 88 条开发轨迹和 310 条测试轨迹。测试集共有 211 条初判拒绝，选择性规则重看 123 条，纠正 0 条成功轨迹的误拒，同时新增 1 条误放行。复核所有拒绝找回 2 条成功轨迹，同时新增 1 条误放行。逐条证据、成功召回率、失败误放行率和置信区间见[正式结果](docs/WEBJUDGE_RESULTS.md)，重跑命令见[实验说明](docs/WEBJUDGE.md)。

原版产物验收模块独立核对指标和业务终态。在 100 个构造的错误结果中，相比只检查格式，误放行由 100 个降至 0 个。100 个合法结果通过，20 种受控的检查缺失均被检出。

这是独立可安装的个人工程项目。原版模块在 2026 年 11 月 1 日完成测量，网页裁判实验在 11 月 5 日单独运行。

先按英文 [README](README.md) 安装，再运行：

```bash
uv sync --locked
uv run pytest -q
uv run python scripts/verify_results.py
```

这三步分别完成依赖安装、离线回归和历史结果复算。需要真实模型调用的命令另见 [运行说明](docs/RUNNING.md)，需自行通过环境变量提供凭据。评测结果及适用范围见 [结果说明](docs/RESULTS.md)，逐条结果在 `results/`。本仓库不包含企业内部材料、访问密钥、大型模型缓存或原始数据库。
